# L-MOHADE

Implementation of **A Learning-driven Hunger-based Adaptive Differential Evolution for Dynamic Economic Emission Dispatch**.

- [Python](python/README.md): DEED implementation, comparison algorithms, and system data.
- [MATLAB](matlab/README.md): benchmark implementation for PlatEMO.
- [Figures](figures/README.md): PDF figure assets.

See the Python and MATLAB instructions for installation and usage.
