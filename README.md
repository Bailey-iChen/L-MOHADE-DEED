# L-MOHADE: A Learning-driven Hunger-based Adaptive Differential Evolution for DEED

This repository contains the Python implementation for the paper:
**"L-MOHADE: A Learning-driven Hunger-based Adaptive Differential Evolution for Dynamic Economic Emission Dispatch"**

## 📢 News

## 📝 Introduction
The **Dynamic Economic Emission Dispatch (DEED)** is a complex, multi-objective optimization problem. This project introduces **L-MOHADE**, a Python-based hybrid framework featuring:
* **Learning-driven Mechanism:** To adaptively calibrate control parameters.
* **Hunger-based Search Strategy:** To balance exploration and exploitation.
* **Arctan-based tvL Gate:** For smooth evolutionary transitions.

## 📂 Repository Structure
* `algorithms/`: Python scripts for L-MOHADE and comparison algorithms.
* `models/`: DEED system models (5-unit to 40-unit) and benchmark functions.
* `utils/`: Data processing and Pareto front visualization tools.
* `main.py`: The main entry point for the optimization.
* `requirements.txt`: List of required Python libraries.

## 🛠 Requirements
* **Python 3.9+** (Developed and tested in **PyCharm 2024.x**)
* Key Libraries: `numpy`, `scipy`, `matplotlib`, `pandas`
